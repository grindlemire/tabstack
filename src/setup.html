Work across your Chrome profiles

Chrome keeps each profile's extensions apart, so tabstack needs a small helper app to work across them. It runs only while Chrome does, and only passes messages between tabstack in your profiles, on this computer.

  • Switch profiles with ⌃⌘→ and ⌃⌘←, each profile's window in the same place
  • Search the tabs in every profile at once
  • Open links in the profile they belong to, like work sites in your work profile
  • Move a tab or open a link in another profile from the right-click menu
  • Hear about it when a page you open is already open in another profile

  1. Install the helper

    With Go, on macOS or Linux:

    go install github.com/grindlemire/tabstack/tabstack-host@latest

  2. Run its setup

    ~/go/bin/tabstack-host install

    It finds tabstack in each of your profiles and opens a tab like this one in each, where you click Allow. That's all.

From the terminal

Every profile, numbered, and how it's connected:

tabstack-host list
